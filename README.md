# سیستم اتوماسیون اداری لیافو

این یک سیستم اتوماسیون اداری ساده برای مدیریت فاکتورها و کاربران در یک ساختار سلسله مراتبی است.

## راهنمای نصب و راه‌اندازی

برای راه‌اندازی این برنامه، مراحل زیر را دنبال کنید:

### ۱. راه‌اندازی پایگاه داده

1.  یک پایگاه داده جدید در هاست سی‌پنل خود با نام `liaphocoffee` ایجاد کنید.
2.  فایل `database.sql` را در پایگاه داده‌ای که ایجاد کرده‌اید، درون‌ریزی (Import) کنید. این کار جداول و داده‌های اولیه (مانند لیست استان‌ها) را ایجاد می‌کند.

### ۲. تنظیمات اتصال به پایگاه داده

1.  فایل `includes/db.php` را باز کنید.
2.  اطلاعات مربوط به اتصال به پایگاه داده خود را در این فایل ویرایش کنید:
    ```php
    $servername = "localhost"; // معمولاً localhost است
    $username = "your_database_user"; // نام کاربری پایگاه داده شما
    $password = "your_database_password"; // رمز عبور پایگاه داده شما
    $dbname = "liaphocoffee"; // نام پایگاه داده
    ```

### ۳. آپلود فایل‌ها

تمام فایل‌ها و پوشه‌های پروژه را در پوشه روت هاست خود (مانند `public_html`) یا هر پوشه دیگری که می‌خواهید برنامه از آنجا اجرا شود، آپلود کنید.

### ۴. ایجاد اولین کاربر (مدیر سیستم)

برای ورود به سیستم، نیاز به یک کاربر اولیه دارید. از طریق phpMyAdmin در سی‌پنل، یک کاربر مدیر سیستم به صورت دستی در جدول `users` ایجاد کنید:

1.  وارد phpMyAdmin شوید و جدول `users` را انتخاب کنید.
2.  روی تب `Insert` کلیک کنید.
3.  مقادیر زیر را وارد کنید:
    *   **username**: `admin` (یا هر نام کاربری دلخواه دیگر)
    *   **password**: برای رمز عبور، از یک ابزار آنلاین برای هش کردن رمز با الگوریتم `PASSWORD_BCRYPT` یا `PASSWORD_DEFAULT` در PHP استفاده کنید. برای مثال، رمز `admin123` به صورت هش شده چیزی شبیه به `$2y$10$92IXUNpkjO0rOQ5byMi.Ye4oKoEa3Ro9llC/.og/at2.uheWG/igi` خواهد بود. این مقدار هش شده را در فیلد `password` قرار دهید.
    *   **role**: `system_manager`
    *   بقیه فیلدها می‌توانند خالی (NULL) باقی بمانند.
4.  روی دکمه `Go` کلیک کنید تا کاربر ایجاد شود.

### ۵. ورود به سیستم

حالا می‌توانید با مراجعه به آدرس سایت خود (مثلاً `http://liaphocoffee.ir`) وارد صفحه ورود شوید و با نام کاربری و رمز عبوری که در مرحله قبل ایجاد کردید، به سیستم وارد شوید.
