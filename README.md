# دستیار هوشمند مرورگر و اتوماسیون وب (AI Browser Assistant)
## پروژه Visual Studio 2019 / .NET Framework 4.8 با C# WinForms

این پروژه یک نرم‌افزار کامل و حرفه‌ای دستیار هوش مصنوعی برای مرورگر وب به زبان **سی‌شارپ (C#)** در محیط **ویژوال استودیو ۲۰۱۹ (Visual Studio 2019)** با **.NET Framework 4.8** است.

---

## 🌟 ویژگی‌های کلیدی سیستم

1. **مرورگر گوگل کروم داخلی (Chromium / Microsoft WebView2):**
   - نمایش کامل وب‌سایت‌ها در پنل سمت راست نرم‌افزار.
   - امکان وب‌گردی عادی، عقب/جلو، به‌روزرسانی و تغییر آدرس URL.

2. **یادگیری رفتاری و ردیابی حرکات موس و کلیک کاربر:**
   - ردیابی زنده تمام کلیک‌های کاربر روی دکمه‌ها، لینک‌ها، متن‌ها و عناصر DOM صفحه.
   - استخراج خودکار متون (مانند `wed` یا `fri` یا `چهارشنبه` و `جمعه`)، کد CSS Selector و XPath.
   - ذخیره‌سازی دائمی الگوهای یادگرفته شده در دیتابیس SQLite جهت استفاده بدون نیاز به هوش مصنوعی مجدد در اجراهای بعدی.

3. **استدلال خودکار و هوش مصنوعی پیشرفته (AI Reasoning Engine):**
   - تحلیل دستورات متنی کاربر به زبان فارسی (مثلاً *"برو سایت کلاس‌ها و روز چهارشنبه رو ببین"* یا *"ساعت کلاس‌های روز جمعه رو برام بیار"*).
   - تشخیص ارتباط میان کلمات فارسی (چهارشنبه، جمعه) و معادل‌های انگلیسی آنها در سایت (`wed` / `fri` / `Wednesday` / `Friday`).
   - کلیک خودکار روی دکمه‌های مربوطه بدون نیاز به دخالت دستی کاربر و پاسخ‌دهی به کاربر با عبارت *"بله متوجه شدم..."* به همراه خلاصه ساعت و تاریخ کلاس‌ها.

4. **مدیریت و کنترل دانش ذخیره‌شده (Knowledge Base Manager):**
   - امکان مشاهده، ویرایش، حذف و افزودن قواعد جدید آموخته‌شده به دیتابیس.
   - به‌روزرسانی دستی الگوها جهت بهینه‌سازی و ارتقای هوش دستیار.

5. **حل مشکل تحریم ایران و پشتیبانی از کلید API رایگان:**
   - پشتیبانی از **OpenRouter** (با مدل‌های رایگان و بدون تحریم مثل `google/gemini-2.5-flash-lite`).
   - پشتیبانی مستقیم از **Google Gemini** و **OpenAI**.
   - امکان تنظیم **Custom Base URL / Proxy Endpoint** جهت عبور از تحریم‌ها بدون نیاز به VPN.
   - راهنمای متنی کامل فارسی درون برنامه برای تنظیم DNSهای ضد تحریم (شکن / ۴۰۳ آنلاین).

6. **ترجمه خودکار محتوای سایت‌ها به فارسی:**
   - قابلیت فعال‌سازی *"ترجمه خودکار صفحه به فارسی"* جهت ترجمه لحظه‌ای کلمات و روزهای هفته در DOM وب‌سایت.

## 🛠️ نحوه اجرا و بیلد در Visual Studio 2019 / 2022

1. فایل `src/AIBrowserAssistant.sln` را با **Visual Studio 2019** (یا جدیدتر) باز کنید.
2. روی Solution راست کلیک کرده و گزینه **Restore NuGet Packages** را بزنید تا بسته‌های زیر دریافت شوند:
   - `Microsoft.Web.WebView2`
   - `Newtonsoft.Json`
   - `System.Data.SQLite.Core`
3. کلید **F5** یا دکمه **Start (Debug)** را فشار دهید تا پروژه بیلد و اجرا شود.

---

## 🔑 راهنمای دریافت کلید API و رفع تحریم ایران

1. برنامه را اجرا کنید و به تب **"⚙️ تنظیمات API و رفع تحریم"** بروید.
2. سرویس‌دهنده را روی **OpenRouter** قرار دهید (آدرس Base URL به صورت خودکار روی `https://openrouter.ai/api/v1` تنظیم می‌شود).
3. به سایت [openrouter.ai](https://openrouter.ai) بروید، یک کلید API رایگان بسازید و در کادر **API Key** وارد کنید.
4. دکمه **"💾 ذخیره تنظیمات API"** را بزنید.

> **نکته عبور از تحریم:** اگر قصد استفاده مستقیم از Google Gemini را دارید، DNS سیستم خود را روی **شکن (`178.22.122.100`)** یا **۴۰۳ آنلاین (`10.202.10.202`)** تنظیم نمایید.

## 📖 نحوه کار با نرم‌افزار

1. **حالت یادگیری با کلیک کاربر:**
   - در مرورگر سمت راست به سایت مورد نظر (مثلاً سایت دانشگاه یا کلاس‌ها) بروید.
   - دکمه‌ای مثل `Wed` یا `Fri` یا لینک کلاس‌ها را کلیک کنید.
   - برنامه به صورت خودکار کلیک شما، آدرس سایت و کلمه روی دکمه را در دیتابیس `ai_knowledge.db` ذخیره می‌کند.

2. **حالت اجرای هوشمند با دستور متنی:**
   - در کادر گفتگو متنی مثل زیر بنویسید:
     - *"برو سایت کلاس‌ها و روز چهارشنبه رو ببین"*
     - *"ساعت کلاس‌های روز جمعه رو بیار"*
   - سیستم ابتدا دیتابیس حافظه را چک می‌کند؛ اگر قبلاً کلیک نموده باشید، مستقیماً روی گزینه مربوطه کلیک کرده و خلاصه ساعت/تاریخ را به فارسی برمی‌گرداند.
   - در صورت عدم وجود سابقه، مدل هوش مصنوعی صفحه را تحلیل کرده، دکمه مربوطه را پیدا کرده و روی آن کلیک می‌کند و الگو را برای دفعات بعدی ذخیره می‌نماید.

3. **ویرایش و بهینه‌سازی یادگیری‌ها:**
   - روی دکمه **"📚 مدیریت دانش ذخیره‌شده"** کلیک کنید تا تمام الگوها، کلمات کلیدی و انتخاب‌گرها را مشاهده، ویرایش یا پاکسازی نمایید.
